## 🌟 ۱. ویژگی‌ها و مشخصات فنی کلیدی (Key Architecture Features)

### 🎨 برندینگ و رابط کاربری اختصاصی (ai petros & Petros Cinema)
- بازطراحی هویت بصری، لوگوی مدرن شاتر سینمایی و هوش مصنوعی (`/public/icon.svg` و `/public/logo.svg`).
- تم تاریک نئونی و طلایی اشرافی (Obsidian Noir & Royal Amber Gold `#F5B942` و Cyber Cyan `#00F0FF`).
- تایپوگرافی سینمایی بین‌المللی و فارسی بهینه‌شده برای پوسترهای سینمایی و صفحه نمایش‌های بزرگ.

### 🔄 سیستم همگام‌سازی زنده و پویای استریم از گیت‌هاب (Dynamic Stream Sync)
- اتصال مستقیم و خودکار کلاینت‌ها به فایل عمومی در گیت‌هاب:  
  `https://raw.githubusercontent.com/aipetrosapp-max/Petros-cinama/main/data/streams.json`
- **بدون نیاز به پنل مدیریت پیچیده:** تغییر یا اضافه کردن لینک‌ها در گیت‌هاب مساوی با آپدیت آنی و زنده ویدیوها در تمام اپلیکیشن‌های نصب‌شده در سراسر دنیا.
- قابلیت کش محلی (Offline First)، زمان‌بندی بررسی خودکار دوره‌ای (Periodic Revalidation)، و دکمه همگام‌سازی دستی با یک کلیک در نوار ابزار بالا و بخش تنظیمات.
- امکان سفارشی‌سازی آدرس مخزن استریم‌ها در تنظیمات برنامه (Custom Stream Source URL).

### 📺 پشتیبانی کامل کراس‌پلتفرم (Cross-Platform Ready)
1. **وب‌اپلیکیشن (Progressive Web App - PWA):** نصب مستقیم بر روی تمام مرورگرها با Service Worker و دسترسی آفلاین.
2. **اندروید موبایل (Android APK) و اندروید تی‌وی (Android TV):**
   - سیستم ناوبری فضایی ریموت کنترل (`tvRemoteNavigation.ts`) هماهنگ با کلیدهای جهت‌نمای D-Pad (بالا، پایین، چپ، راست، Enter و Back).
   - رینگ فوکوس درخشان طلایی برای مشاهده از فاصله ۳ متری (10-Foot UI).
   - کانفیگ استاندارد `android.software.leanback` در فایل Manifest و قابلیت اجرا بدون نیاز به صفحه لمسی.
3. **دسکتاپ ویندوز و مک‌اواس (Windows & macOS):**
   - پیکربندی فوق‌سبک با فریم‌ورک مدرن **Tauri** (`src-tauri/tauri.conf.json`).
   - اسکریپت اجرای محلی دسکتاپ با **Electron** (`electron-main.cjs`).

### 💎 تبلیغات هوشمند و درآمدزایی کریپتویی بدون نیاز به احراز هویت (No-KYC Crypto Monetization)
- **شبکه تبلیغاتی غیرمتمرکز A-Ads (Anonymous Ads):** قدیمی‌ترین و معتبرترین شبکه تبلیغاتی کریپتو فعال از سال ۲۰۱۱ با حفظ حریم خصوصی ۱۰۰٪، بدون نیاز به کوکی‌های ردیابی و بدون احراز هویت (Zero KYC).
- **الگوریتم نمایش هوشمند و غیرآزاردهنده:**
  - تواتر کنترل‌شده (نمایش مدال حامی تنها پس از تماشای هر ۲ الی ۳ ویدیو، نه به صورت اسپم).
  - تایمر ملایم ۵ ثانیه‌ای همراه با دکمه شفاف رد کردن (Skip Ad).
  - بنرهای تخت و مدرن کریپتویی در پایین صفحه پلیر و خانه.
- **صندوق حمایت مستقیم رمزارزی (Crypto Tip Vault):** پشتیبانی از آدرس‌های رسمی بیت‌کوین (BTC SegWit)، تتر ترون (USDT-TRC20)، اتریوم (ETH) و تون‌کوین (TON).

## 🚀 راهنمای نصب و راه‌اندازی (Getting Started)

### ۱. اجرای نسخه توسعه (Web Development)
```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه فرانت‌اند
npm run dev
```

### ۲. ساخت بیلد نهایی وب (Production Web Build)
```bash
npm run build
```
پوشه `dist/` با تمام بهینه‌سازی‌ها، تگ‌های سئو و فایل‌های مانیفست آماده استقرار است.

### ۳. ساخت خروجی اندروید و اندروید تی‌وی (Android & Android TV)
```bash
# بیلد و همگام‌سازی با Capacitor
npm run build:android

# باز کردن پروژه در Android Studio برای خروجی APK
npx cap open android
```
*(برای جزئیات بیشتر به فایل [android/README.md](android/README.md) مراجعه فرمایید).*

### ۴. ساخت خروجی دسکتاپ (Windows & macOS)
```bash
# خروجی با Tauri (سبک و سریع)
npm run build:desktop

# یا اجرای مستقیم روی دسکتاپ با Electron
npm run desktop:electron
```

## 📡 نحوه ویرایش و اضافه کردن ویدیوها به صورت زنده (Dynamic Sync)
کافیست فایل `data/streams.json` در همین ریپازیتوری را ویرایش کرده و کامیت کنید:
```json
{
  "id": "petros-stream-new",
  "title": "فیلم جدید من",
  "titleFa": "نام فارسی فیلم",
  "synopsisFa": "توضیحات فارسی...",
  "category": "cinema",
  "posterUrl": "https://example.com/poster.jpg",
  "durationSec": 7200,
  "defaultStreamUrl": "https://example.com/stream.mp4",
  "qualities": [
    { "quality": "4K", "url": "https://example.com/stream-4k.mp4" },
    { "quality": "1080p", "url": "https://example.com/stream-1080p.mp4" }
  ]
}
```
تمام اپلیکیشن‌ها و کاربران در اجرای بعدی یا در دوره‌های ۵ دقیقه‌ای به صورت خودکار فیلم جدید را در صفحه اصلی مشاهده خواهند کرد!
